# Tax Report — Organizador de Dados para o Imposto de Renda

## 📌 Sobre o projeto

O Tax Report é uma ferramenta desenvolvida no Microsoft Excel 2019 com o objetivo de facilitar a organização e a centralização de informações necessárias para a preparação da declaração anual do Imposto de Renda.

A proposta consiste em reunir dados pessoais, informações sobre rendimentos bancários e registros de entradas financeiras em uma estrutura organizada, com navegação entre seções e recursos que facilitam o preenchimento e a consulta dos dados.

O projeto foi desenvolvido como parte de um desafio prático de aprendizagem, aplicando funcionalidades do Excel na construção de uma ferramenta com interface amigável.

## 🎯 Objetivos

- Centralizar informações relevantes para a preparação da declaração do Imposto de Renda.
- Organizar dados pessoais e informações financeiras.
- Facilitar o preenchimento e a consulta dos registros.
- Padronizar entradas por meio de validações e listas de seleção.
- Automatizar cálculos que podem ser realizados diretamente na planilha.
- Aplicar conceitos de Excel e documentação técnica em um projeto prático.

## ⚙️ Funcionalidades

O modelo de referência do projeto apresenta recursos como:

- **Cadastro de dados pessoais:** organização das informações do titular.
- **Registro de informes bancários:** preenchimento das instituições financeiras, valores e referências aos documentos comprobatórios.
- **Controle de entradas financeiras:** registro de data, categoria e valor.
- **Validação de dados:** utilização de opções predefinidas para padronizar determinados campos.
- **Cálculos automáticos:** consolidação de valores por meio de fórmulas.
- **Navegação entre seções:** organização do preenchimento em etapas.
- **Interface visual:** uso de cores, campos destacados e elementos de navegação para facilitar a utilização.

## 🧰 Tecnologias e recursos utilizados

- Microsoft Excel 2019.
- Fórmulas e funções do Excel.
- Validação de dados e listas suspensas.
- Formatação de células e organização de tabelas.
- Recursos de navegação e referências a documentos.
- GitHub para versionamento e compartilhamento da documentação.

## 📖 Como utilizar

1. Abra o arquivo Excel.
2. Consulte as instruções e as seções disponíveis na ferramenta.
3. Preencha os campos solicitados com informações corretas e atualizadas.
4. Registre os valores financeiros e mantenha os documentos comprobatórios organizados.
5. Confira os totais e os demais resultados calculados pela planilha.
6. Revise os dados antes de utilizá-los na preparação da declaração.

## ⚠️ Observações

O Tax Report tem como finalidade auxiliar na organização de informações. A ferramenta não substitui o programa oficial da Receita Federal, não garante por si só a correção de uma declaração e não dispensa a conferência das regras tributárias aplicáveis.

Para preservar a privacidade, não compartilhe em repositórios públicos dados pessoais reais, números de CPF, informes bancários, comprovantes de rendimentos ou outros documentos confidenciais.

## 📚 Aprendizados

O desenvolvimento deste projeto permite praticar a organização de dados no Excel, a aplicação de fórmulas, a validação de entradas, a construção de interfaces mais intuitivas e a documentação de soluções técnicas utilizando o GitHub.
